## 🪐 [Precourse 1주차] 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

---

### ✨ 구현할 기능 목록

1. 사용자 입력 처리
2. 입력값 검증
   - 빈 문자열 체크 → 0 반환
   - 음수 또는 숫자가 아닌 값 입력 시 → Error
   - 숫자 앞뒤 공백 제거
3. 구분자 처리
   - 기본 구분자 “,” 또는 “:”
   - 커스텀 구분자 “//$구분자\n”
   - 값 없이 커스텀 구분자만 입력한 경우 → Error
   - 구분자가 숫자인 경우 -> Error
   - 구분자 사이에 값이 없는 경우(연속 구분자) → Error
4. 구분자를 기준으로 문자열 분리
5. 문자열에서 숫자로 변환
6. 모든 숫자의 합계 계산
7. 계산된 합계 출력

---

### 📁 src 디렉토리 구조

```bash
src/
├── App.js
├── index.js
├── Calculator.js        # 계산기 로직(문자열 처리, 합 계산)
├── constants.js         # 상수 파일(기본 구분자, 에러 메세지)
├── validators.js        # 입력값, 구분자 검증
└── utils.js             # 유틸 함수(문자열 분리, 숫자 변환)
```

### 💡 트러블 슈팅, 고민했던 부분

- 기능을 모두 만든 후 에러 처리를 한 번에 할지, 아니면 기능별로 진행할지 고민했다.
  처음에는 기능을 구현할 때마다 에러를 처리하는 것이 디버깅에 유리하다고 판단했다. 하지만 초기 단계에서는 동작하는 프로토타입을 우선 만드는 것이 효율적일 수 있어, 이후 단계에서 에러 처리를 추가하기로 했다. 그래서 구현할 기능 목록 중 “3번 구분자 처리”부터는 먼저 전체적인 기본 동작을 구현한 뒤, 이후 안정화 작업을 진행했다.
- 문제에 대해 생각하면 할수록 에러 처리할게 많아져서, 할 수 있는 만큼 최대한 구현해 보았다. 앞으로 과제동안 에러 처리 개수를 늘려나가야겠다.

- 이번 과제를 통해 정규표현식을 체계적으로 이해할 수 있었다.
  예전에는 코딩테스트 풀이에서 정규표현식을 보면 신기하고 어렵게 느껴졌지만, 이제는 나도 이를 활용해 더 간결하고 효율적인 알고리즘을 구현할 수 있을 것 같다.
