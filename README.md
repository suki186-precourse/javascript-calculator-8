## 🪐 [Precourse 1] 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

> indent(인덴트, 들여쓰기) depth는 최대 2까지.
> 3항 연산자 쓰지 않기.
> 함수는 한 가지 일만 하도록 최대한 작게.

---

### ✨ 구현할 기능 목록

**🔹 기본 기능**

1. 입력

- [ ] Console.readLine()를 사용해 사용자로부터 문자열 입력 받기

1. 구분자 분리

- [ ] 기본 구분자 기준으로 문자열 분리
- [ ] 커스텀 구분자 추출 및 문자열 분리

1. 합 계산

- [ ] 분리된 문자열을 숫자로 변환
- [ ] 변환된 숫자들의 합 계산

1. 출력

- [ ] 결과 값 출력

**🔹 예외 처리**

1. 전체 입력값 검증

- [ ] 빈 문자열을 입력한 경우 → 0 반환

1. 양수 검증

- [ ] 양수가 아닌 값을 입력한 경우(음수, 문자)
- [ ] 앞 뒤에 공백을 입력한 경우

1. 구분자 검증

- [ ] 구분자가 숫자인 경우
- [ ] 구분자만 입력된 경우
- [ ] 구분자가 연속으로 입력된 경우
