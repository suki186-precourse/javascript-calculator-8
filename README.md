## 🪐 [Precourse 1주차] 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

---

### ✨ 구현할 기능 목록

1. 사용자 입력 처리
2. 입력값 검증
   - 빈 문자열 체크 → 0 반환
   - 음수 또는 숫자가 아닌 값 입력 시 → Error
   - 숫자 앞뒤 공백 제거
3. 구분자 처리
   - 기본 구분자 “,” 또는 “:”
   - 커스텀 구분자 “//$구분자\n”
   - 값 없이 커스텀 구분자만 입력한 경우 → Error
   - 구분자가 숫자인 경우 -> Error
   - 구분자 사이에 값이 없는 경우(연속 구분자) → Error
4. 구분자를 기준으로 문자열 분리
5. 문자열에서 숫자로 변환
6. 모든 숫자의 합계 계산
7. 계산된 합계 출력

---

### 📁 src 디렉토리 구조

```bash
src/
├── App.js
├── index.js
├── Calculator.js        # 계산기 로직(문자열 처리, 합 계산)
├── constants.js         # 상수 파일(기본 구분자, 에러 메세지)
├── validators.js        # 입력값, 구분자 검증
└── utils.js             # 유틸 함수(문자열 분리, 숫자 변환)
```
